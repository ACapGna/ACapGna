## 🚀 Proyecto destacado: Fidel

Plataforma de fidelización para comercios que unifica **tarjetas de puntos, tarjetas de sellos y niveles VIP** en una sola base de código, desarrollada durante mis prácticas en Plocos (mayo de 2026).

- **Backend:** Fastify + TypeScript sobre MongoDB, con autenticación JWT, datos aislados por comercio y un motor de reglas que actualiza puntos, sellos y niveles al registrar una compra.
- **Pagos:** suscripciones con Stripe; el panel pasa a solo lectura si caduca el pago.
- **Frontend:** React + Vite, con buscador de comercios por geolocalización y tarjetero virtual con escáner de QR y códigos de barras.
- **Infraestructura:** Docker Compose, monorepo con Bun y preparada para móvil con Capacitor.
